Capacity Monitor for Codex

Before the extension requests your Codex quota, review what it accesses and what stays local.

What it accesses

  • Your authenticated ChatGPT session, only to request Codex quota/rate-limit metadata.
  • Quota percentage, reset timing, window metadata, plan label, and reset-credit metadata when available.

A short-lived ChatGPT access token is used in memory for the quota request and is not stored. If a direct request fails, the extension can make the same request inside an open ChatGPT tab; it does not read the page DOM.

What it does not intentionally read

  • ChatGPT prompts or conversation text.
  • Passwords or unrelated browsing history.

Local data

Normalized quota snapshots, inferred sessions, alerts, diagnostics, and settings are stored in Chrome local extension storage in this browser profile.

Optional external alerts

Email, Telegram, Discord, and generic webhooks are off by default. Enabling one requests HTTPS access to its exact origin and sends only alert data needed for that channel. Integration credentials are stored locally and are not independently encrypted by this project.

This is an independent project and is not affiliated with or endorsed by OpenAI. Quota reporting uses an internal, undocumented ChatGPT endpoint and may stop working if OpenAI changes it.
