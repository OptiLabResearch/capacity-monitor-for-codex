Capacity Monitor for Codex

Independent, local-first capacity monitor for Codex subscription usage. Not affiliated with or endorsed by OpenAI.

Single purpose: monitor Codex capacity, analyze locally observed quota usage, and notify you about low capacity and resets.

Quota reporting uses an internal ChatGPT usage endpoint because no public subscription-quota API is currently provided. OpenAI changes may temporarily break reporting.
