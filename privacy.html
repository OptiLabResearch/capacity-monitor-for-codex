Privacy policy

Capacity Monitor for Codex is independent, local-first, and not affiliated with or endorsed by OpenAI.

Access and purpose

After consent, the extension accesses the authenticated ChatGPT session only to request Codex quota/rate-limit metadata from an internal, undocumented endpoint. It uses that data for capacity display, observed history/pacing, and alerts. It does not intentionally read prompts or conversation text. The short-lived access token is not stored.

Local storage and deletion

Normalized snapshots (up to 180 days/12,000 points), reset events, inferred sessions, alert history, diagnostics, consent, and settings are stored in chrome.storage.local. Use Dashboard → Data & privacy to delete history or all local extension data.

Optional transmissions

Core quota requests go to OpenAI/ChatGPT. Browser alerts stay local. Email relay/Brevo, Telegram, Discord, and generic webhook delivery are off by default. When enabled, minimal alert metadata goes only to the provider/endpoint the user configured. No developer analytics, ads, or telemetry are included.

Credentials

Integration credentials are stored in the Chrome profile and are not independently encrypted by this project. Backups and diagnostics exclude sensitive integration fields. The Brevo API key belongs only in Worker secret storage—never in the extension.

Reliability

OpenAI may change or remove the internal endpoint without notice. Unknown data fails closed; the extension does not invent quota history or projections.

For complete retention, sharing, security, and limited-use details, see PRIVACY.md in the public repository.
